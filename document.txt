Accessibility & performance

Use semantic HTML, aria-labels for buttons and images, alt text for property photos.

Lazy-load images (progressive JPEG / WebP), use image placeholders / skeletons.

Use responsive image sizes (srcset), compress assets.

Keyboard navigation and focus-visible states for key interactive elements.

Lighthouse aims: Performance > 50 (mobile), Accessibility > 90.

Animation plan (concrete)

Page transitions: use Framer Motion <AnimatePresence> with opacity + slight y translation (fast 150–200ms).

Hero listing reveal: GSAP timeline for image parallax + overlay text reveal (when loading property). Use ScrollTrigger if you want scroll-driven animations on Detail page.

Filter drawer & modals: Framer Motion’s spring-driven y slide with backdrop fade.

Lenis: enable for long-scrolling sections (locality maps or blog/product pages). Initialize Lenis at app root; disable on small devices if performance issues.

Micro-interactions: button press scale, saved / liked heart toggle, filter chip toggle using Framer Motion whileTap/whileHover.

Provide animation durations (guidelines): micro 80–140ms, normal 200–360ms, complex timeline 600–1200ms.

Example (Framer Motion small pattern):

<motion.button
  whileTap={{ scale: 0.96 }}
  whileHover={{ scale: 1.02 }}
  transition={{ type: 'spring', stiffness: 300, damping: 18 }}
>
  Contact Owner
</motion.button>
